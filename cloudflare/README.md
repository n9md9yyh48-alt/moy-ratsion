# Мой рацион — Cloudflare Free + OpenAI API

**Состояние 9 ноября 2026: код и тесты подготовлены, аккаунты не подключены, сервер НЕ развёрнут, платежей не было.** Пользователь согласовал первый бюджет **$5** — без автоматического продления или повышения.

## Устройство

- [worker.mjs](worker.mjs) — HTTPS-посредник между PWA и OpenAI, с проверкой запроса и авторизацией.
- [budget.mjs](budget.mjs) — постоянный Durable Object на базе SQLite для единого бюджета; хранит только суммы и случайные идентификаторы, без фото и текстов.
- [wrangler.jsonc](../wrangler.jsonc) — Free plan с моделью gpt-6.1-terra.
- В приложении [ai-config.js](../ai-config.js) пока пустой. Чат и фотоанализ отключены.
- Старый [Node HTTP server](../server/http.mjs) нельзя использовать для платной эксплуатации: его счетчики находятся только в памяти и не ограничивают расходы по месяцам.

## Контроль расходов: три уровня

1. Создать отдельный OpenAI API-проект «Мой рацион». В Project > Limits установить Monthly spend limit = **$5**, включить **Enforce a hard limit**. Настроить предупреждения на $2.50 и $4.00. Hard limit может сработать с задержкой.
2. Купить **ровно $5 предоплаченных API-кредитов** и обязательно **выключить Use auto-reload**. По умолчанию при настройке автопополнение может быть включено. Перед оплатой проверить налоги и итоговую сумму.
3. Worker постоянно резервирует 5 центов перед обработкой фото или 2 цента перед сообщением в чате. При ответе OpenAI резерв заменяется расчётом по фактически указанным input/output токенам Terra с 30% запасом. При ошибке оставляет полную сумму резерва заблокированной. Считает не более 3 обращений в минуту и 20 за сутки; при достижении $5 не пропускает новые запросы.

Worker считает **приблизительную стоимость** (не сумму по настоящему счёту). Возможны расхождения при изменении тарифов, неполной статистике или задержке применения лимита. Фактические затраты смотреть в OpenAI Usage/Billing.

## Что потребуется для реального запуска

- Доступ владельца к Cloudflare Workers Free и OpenAI API (можно подключить только после подтверждения у владельца, без передачи секретов в чат).
- В Cloudflare добавить **Secrets**: OPENAI_API_KEY из отдельного OpenAI-проекта, AI_ACCESS_TOKEN — случайный пароль >=32 символов. Не писать их в GitHub, Notion, файлы настроек или чат.
- Развернуть Worker конфигурацией Wrangler, предварительно запустив тесты. Используется SQLite-backed Durable Object через exports, ручная схема SQL не требуется.
- Проверить маршрут /health, затем приватный /api/budget с Bearer-токеном: лимит $5, изначально потрачено $0. Протестировать по одному фото и сообщению и сравнить затраты с OpenAI Usage.
- Только после проверки указать HTTPS-адрес Worker в публичном ai-config.js. В него нельзя добавлять токен.
- Не включать платный Cloudflare Worker, подписки или другие хостинги без нового согласования.

## Безопасность и ограничения

- Запросы идут только в OpenAI Responses API. OpenRouter и другие сервисы исключены.
- Кнопки требуют действий пользователя, фотография и недельная сводка не отправляются автоматически.
- API ключ находится исключительно на сервере, лимиты сохраняются между перезапусками, и без реестра платные вызовы запрещены.
- Общий приватный токен пока потребуется вводить на каждый запрос. До комфортного релиза следует отдельно улучшить авторизацию, не помещая общий токен в JavaScript.
- Успешные автоматические тесты не заменяют финальную проверку Safari на iPhone.
- Не объявлять сервер запущенным или бюджет оплаченным до фактического выполнения обоих действий.
