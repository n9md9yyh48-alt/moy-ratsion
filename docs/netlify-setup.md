# Бесплатная публичная ссылка «Мой рацион» через Netlify

Цель: выдать новым пользователям короткий адрес вида `https://moy-ratsion.netlify.app/` без покупки домена, **не затрагивая уже установленный iPhone PWA на GitHub Pages**.

## Однократное подключение владельцем

1. Перейти на <https://app.netlify.com/start> и войти через GitHub.
2. В Netlify выбрать **Add new project → Import an existing project** (или «Import from Git»), провайдер **GitHub**.
3. При запросе доступа разрешить Netlify импорт репозитория `n9md9yyh48-alt/moy-ratsion`. Предпочтительно дать доступ только этому репозиторию, а не всем.
4. Выбрать **main**, настройки: **Base directory** — пусто, **Build command** — пусто (приложение уже готово), **Publish directory** — `.`. В корне репозитория есть `netlify.toml` с тем же `publish = "."`.
5. Нажать **Deploy / Publish** и дождаться состояния **Published**. В настройках проекта выбрать **Customize** → имя `moy-ratsion`, если свободно. Если занято, выбрать `moy-ratsion-app` или `moy-ratsion-dnevnik` — **не считать варианты доступными, пока Netlify не подтвердит**.
6. Убедиться, что сайт публичный и доступен без авторизации (у новых Netlify-команд может быть включена приватность по умолчанию).
7. Проверить фактически выданную Netlify ссылку в браузере: «Сегодня», «Рецепты», «💬 В чат», создание тестовой записи, перезагрузка. Только после этого делиться ею с друзьями.

## Важные границы

- GitHub Pages <https://n9md9yyh48-alt.github.io/moy-ratsion/> остаётся **без изменений**. Нельзя делать редирект с него, переустанавливать старое приложение, менять его адрес или очищать Safari — иначе локальные записи могут оказаться недоступны.
- `localStorage` различается между GitHub Pages и Netlify. На новом адресе **будет пустой дневник**. Если владелец позже захочет пользоваться новым адресом на своём iPhone, перенести данные нужно вручную через уже скачанный JSON; копировать запись в новый дневник после явного согласия и проверки копии.
- Обновления кода в GitHub `main` после настройки Netlify автоматически публикуются и на новом Netlify-сайте. Старый GitHub Pages продолжит обслуживать установленное PWA.
- Приобретение домена не требуется; отдельный OpenAI API и серверная оплата не используются.
- Не передавать в публичный репозиторий резервные копии личного дневника, фото и ключи доступа.

Официальные инструкции: <https://docs.netlify.com/start/quickstarts/deploy-from-repository/> и <https://docs.netlify.com/manage/projects/customize-project-name-and-cover-image/>.
