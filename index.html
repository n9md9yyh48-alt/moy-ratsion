Приватность

Эта версия работает локально: записи остаются в браузере устройства. Очистка данных браузера удалит их. Нет облачной синхронизации и авторизации. Обмен с ChatGPT выполняется только вручную по твоему решению.

Перед восстановлением или удалением данных сохрани резервную копию в разделе «Отчёты».

Как установить на iPhone

Открой опубликованный HTTPS-адрес в Safari → «Поделиться» → «На экран Домой». Для работы без интернета потребуется сначала открыть приложение онлайн. Если приложение уже установлено, заново добавлять его на экран не нужно.

💬 Вместе с ChatGPT

Продолжай присылать фотографии еды в нашу беседу. Я рассчитываю КБЖУ и даю код для добавления записи в этот дневник. Отдельный платный ИИ не нужен.

Дневник хранится только на этом устройстве. ChatGPT не видит его автоматически и не может сам добавить или изменить записи.

Как добавить еду из чата

После расчёта я дам ссылку и код. Открой эту ссылку в установленном «Моём рационе» или скопируй код и вставь в разделе «Сегодня → 📥 Добавить запись из чата».

Если ссылка открылась в обычном Safari, сохранение может оказаться отдельно от дневника на домашнем экране iPhone. Надёжнее вставить код внутри установленного приложения.
